# Budget Tracker

A simple, responsive, and beginner-friendly Budget Tracker web application built with HTML, CSS, JavaScript, and Bootstrap. Easily track your income and expenses, visualize your spending, and maintain personal finance records locally in your browser.

## 🚀 Features

- **Income & Expense Tracking**: Add, edit, and delete transactions with ease.
- **Financial Summary**: Real-time calculation of total income, total expenses, and current balance.
- **Search & Filter**: Search transactions by description and filter by income or expense category.
- **Sorting**: Sort your transaction history by date or amount.
- **Data Visualization**: Visual chart breakdown of your expenses.
- **JSON Export**: Export transaction records in JSON format.
- **LocalStorage Persistence**: Data is automatically saved in your browser's LocalStorage (`transactions`).
- **Responsive Design**: Clean and mobile-friendly UI built with Bootstrap 5.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Bootstrap 5**
- **Browser LocalStorage**

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/neeldarji12/Budget-tracker.git
   ```
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

> No Node.js, MongoDB, Firebase, or backend server is required!

## 💾 Data Storage

All transaction data is stored locally in your browser under the key:
```
transactions
```
